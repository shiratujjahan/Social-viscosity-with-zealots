# Social-viscosity-with-zealots

This repository contains the code used in the manuscript *“Social Viscosity Mechanisms with Zealots”*. It includes:

1. **Mathematica notebooks** used for symbolic stability analysis of five social viscosity mechanisms:
   - Direct Reciprocity  
   - Indirect Reciprocity  
   - Kin Selection  
   - Group Selection  
   - Network Reciprocity  
   (with and without zealous cooperators and defectors)

2. **MATLAB scripts** used for numerical simulations and figure generation.

---

## Requirements

To reproduce the analytical results and figures, you will need:

- Wolfram Mathematica (version 13.0 or higher recommended)
- MATLAB (R2021a or higher recommended)

---

## How to Reproduce Results

### 1. Stability Analysis (Mathematica)

1. Download the repository, and open the appropriate `.nb` notebook in Mathematica.
2. Evaluate all cells sequentially (Evaluation → Evaluate Notebook).
3. The symbolic stability conditions and analytical thresholds will be derived automatically.

### 2. Numerical Simulations and Figures (MATLAB)

1. Open MATLAB.
2. Navigate to the folder containing the MATLAB scripts.
3. Run the main simulation script (e.g., `main_simulation.m`).
4. Output figures will be saved in the working directory.
1. Open *MATLAB*.
2. Navigate to the `MATLAB/` folder.
3. Run: main_simulation.m
